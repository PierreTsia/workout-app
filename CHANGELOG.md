## [1.0.0](https://github.com/PierreTsia/workout-app/releases/tag/v1.0.0) (2026-10-01)

### Initial release

The baseline release: GymLogic as it stands in production — the training PWA
(sessions, programs, cycles, history, achievements, Profil) and the MCP server
(`create_program`, `update_program`, `create_workout_day`, catalog and training
read tools). Subsequent versions are generated automatically.
