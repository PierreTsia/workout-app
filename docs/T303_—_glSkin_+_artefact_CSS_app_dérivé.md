# T303 — glSkin + artefact CSS app dérivé

## Goal

Introduire le **skin GL nommé** (`glSkin`), un overlay DTCG d'identité, et faire dériver le CSS de l'app depuis lui via `renderCss(resolveSkin(default, glSkin))` — produit par un script et committé comme artefact. Couvre les stories 5, 6, 10, 11 de l'Epic Brief : source unique, artefact gardé, valeurs GL possédées, échec bruyant sur slot inconnu.

## Mode

AFK — création de fichier + script + import + CI, critères mécaniques.

## Slice

`src/styles/glSkin.json → scripts/build-gl-skin.mjs → src/styles/glSkin.generated.css → globals.css (import) → package.json + ci.yml + arch test`

## Dependencies

None.

## Scope

### `src/styles/glSkin.json`

Overlay DTCG, **valeurs littérales** par mode, **aucun `primitive`**, groupes : `color.*` (fond, surfaces, primaire/secondaire, muted, accent, destructive, border/input/ring, brand, status-*), `radius.*` (`pill`/`control`/`field`/`chip`), `type.*` (`family.sans`, `weight.*`, `size.*`, `leading.*`).

- Valeurs **identiques** aux valeurs résolues du défaut actuel (teal `174 100% 39%` dark / `174 100% 35%` light, surfaces `240 7% 8%`, etc.) — extraire une fois depuis `@nomosui/react/tokens/tokens.json`.
- Forme par slot : `{ "$value": { "dark": "…", "light": "…" } }` (ou valeur unique si identique par mode).

### `scripts/build-gl-skin.mjs`

- Importe `resolveSkin`, `renderCss` depuis `@nomosui/react` (surface publique seule).
- Lit `@nomosui/react/tokens/tokens.json` (défaut) + `src/styles/glSkin.json`.
- `writeFileSync('src/styles/glSkin.generated.css', renderCss(resolveSkin(defaultTokens, skin)))` avec en-tête `Generated by scripts/build-gl-skin.mjs — do not edit by hand. Replay: npm run glSkin`.
- Mode `--check` : compare au fichier committé, `exit 1` si dérive (calque `scripts/build-mcp-view.mjs`).

### `src/styles/globals.css`

- Remplace `@import '@nomosui/react/tokens/tokens.generated.css'` par `@import './glSkin.generated.css'`.
- **Ne touche pas** au `@theme` legacy ni aux blocs `:root/.dark/.light` (retrait en T306) — l'artefact étant value-identique, aucun changement visuel.

### `package.json` + `.github/workflows/ci.yml`

- Script `"glSkin": "node scripts/build-gl-skin.mjs"`, `"glSkin:check": "node scripts/build-gl-skin.mjs --check"`.
- CI : exécuter `glSkin:check` (avant `view:check`, voir T304).

### Arch test `src/test/glSkin.arch.test.ts`

- `glSkin.json` ne contient pas de clé `primitive`.
- `scripts/build-gl-skin.mjs` appelle `resolveSkin` **et** `renderCss` et gère `--check`.
- `glSkin.generated.css` contient `--nomos-color-primary: 174 100% 39%`.
- `globals.css` importe `./glSkin.generated.css`.
- `package.json` porte `glSkin:check`.

## Out of Scope

- Retrait du `@theme` legacy (T306).
- Build des vues (T304).
- Migration des usages directs (T305).

## Acceptance Criteria

- [ ] `npm run glSkin` génère `src/styles/glSkin.generated.css` ; `npm run glSkin:check` est vert sur un checkout propre.
- [ ] L'app boote avec un rendu **identique** à avant (aucune valeur ne change) : `renderCss(resolveSkin(default, glSkin))` == contenu de l'ancien `tokens.generated.css`.
- [ ] `glSkin.json` ne porte aucun `primitive` ; un slot inconnu ajouté à la main fait échouer `npm run glSkin`.
- [ ] `npm run lint` et `npm test` verts (dont le nouvel arch test).
- [ ] La CI exécute `glSkin:check`.
